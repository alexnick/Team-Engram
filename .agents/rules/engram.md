# Team Engram Rule

Always follow `.agents/AGENTS.md` and `Protocols/Team-Engram-Protocol.md`.

Load context progressively through `CONTEXT-MAP.md`, the locally generated ignored `Engram/INDEX.md`, and relevant corpus pages. Keep project-specific truth in project repositories and reusable organizational knowledge in Team Engram.

Treat merged `main` as canonical. Distinguish maintained knowledge, source claims, decisions, and agent inference. Preserve raw source snapshots and locators; edit derived source records and Knowledge only in a focused local change.

Inspect Git status before writing and preserve unrelated work. Validate locally, summarize the proposal, and wait for explicit `Publish this change` confirmation before commit, push, or Merge Request creation or update. Never merge.

Keep all repository artifacts in English. Conversation may use the user's preferred language.
