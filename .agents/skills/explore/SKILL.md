# Explore

Improve the user's model of an unclear idea through focused, adaptive questioning. Explore is conversation-only in Team Engram: it creates no session note and makes no repository change.

## Procedure

1. Load only clearly relevant Team Engram and attached-project context. State briefly what informed the discussion.
2. Establish the desired outcome, constraints, terminology, and unresolved assumptions.
3. Ask one high-value question at a time. Adapt the next question to the answer rather than following a fixed questionnaire.
4. Surface alternatives, trade-offs, contradictions, and disconfirming examples before converging.
5. Periodically restate the current model and ask the user to correct it.
6. Finish with current understanding, strong conclusions, open questions, risks, and possible durable changes.

## Durable handoff

Do not implement or write during Explore. After the user confirms the conclusion, route project-specific results to the project repository under its rules. Route reusable organizational synthesis to `update-team-engram`. It is valid to leave the result only in conversation.

## Completion

The user's terms and constraints are explicit, material alternatives were considered, open branches are visible, and no persistent Team Engram session or semantic edit was created.
